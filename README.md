# Less Than 3 Days: Relay team workspace

This repository is the shared GitHub project for the team's Switch and Discord collaboration trial. Discord is the conversation; Switch connects that conversation to agents; this repository holds the brief, code, tests, and Git history.

## Start here

1. Read [the project brief](docs/PROJECT_BRIEF.md).
2. Read [the team workflow](docs/TEAM_WORKFLOW.md).
3. The Switch owner can copy the [room instructions](switch/ROOM_INSTRUCTIONS.md) into the project room and the [agent profiles](switch/agents/README.md) into Switch Console.
4. The first coding assignment is the initial registration-and-waitlist behavior in the brief. It is deliberately unimplemented so the team can watch a real Builder → Reviewer handoff.

No model credentials, Discord tokens, or GitHub secrets belong in this repository.
